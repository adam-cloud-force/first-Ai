# 🚀 Getting Started - Your AI Assistant

## Quick Start (2 minutes!)

1. **Run your AI assistant**:
   ```bash
   python3 simple_ai.py
   ```

2. **Try these commands** to see your AI in action:
   ```
   calculate 15 + 27
   explain neural networks
   what time is it?
   remember I love coding
   let's play a game
   help
   ```

3. **To exit**: Type `quit` or press `Ctrl+C`

## 🎯 What Your AI Can Do

✅ **Math Calculator** - Solve equations and do calculations  
✅ **Learning Tutor** - Explains AI and programming concepts  
✅ **Memory System** - Remembers things you tell it  
✅ **Games & Fun** - Interactive games and riddles  
✅ **Smart Conversation** - Natural language chat  
✅ **Time & Date** - Current time and date information  

## 📁 Project Files

- `simple_ai.py` - Your main AI assistant (no dependencies needed)
- `main.py` - Advanced version with more features (requires dependencies)
- `README.md` - Complete project documentation
- `learning_guide.md` - In-depth AI concepts explained simply
- `requirements.txt` - Python packages for advanced features
